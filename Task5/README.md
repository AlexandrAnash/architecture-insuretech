# Задание 5. Выводы по GraphQL

- Если экрану нужны имя клиента, номера документов и имена родственников, по текущему REST-контракту понадобятся три HTTP-запроса. В GraphQL эти данные можно получить одним запросом к `client(id: ...)`.
- Каждый экран запрашивает только нужные поля. Если нужно одно имя, HTTP-запрос по-прежнему один, но ответ содержит только `name`. Данные о родственниках можно запросить позже, когда пользователь откроет этот раздел.
- Один HTTP-запрос может вызвать несколько чтений из БД. Число обращений к БД зависит от того, как `client-info` загружает данные для выбранных полей.
